# Kim Hyunji — Portfolio

Neon-yellow and orange personal portfolio website.

## Categories
- **About** — introduction, CV, and social links
- **AI-Generated Reports** — AI automation, company analysis, and dashboards
- **Qualifications & Certifications** — certificates and verification links
- **Activities** — school activities, competitions, and projects

## Run locally
Open `index.html` in a browser. No build step is required.
